# 后续配色调整

状态：待实施。本清单不包含在 v2.0.0 的界面改动中；先保留并推送当前已部署版本。

1. **仓位图形**：柱形从红、黄到绿逐渐升高；上行箭头使用绿色或币安黄色。参考苹果的鲜明配色和克制的色彩层次。浅色、深色都需要检查。
2. **风险建议**：将“每笔风险建议上限”中的“≤ 2%”显示为绿色，提供正向暗示。
3. **时间提醒**：夜深、早上等问候加入适当颜色和表情，表达更有人情味。优先使用系统原生 emoji；苹果设备可自然显示 Apple 风格，其他系统使用其原生表情字体。
4. **交易所选择**：支持币安，条件允许时配图标；候选项／鼠标悬停使用交易所主题色。币安黄色、OKX 白色、Bitget 和火币各自品牌色。选中后的文字可保持当前白色。实施前核实实际品牌规范，并保证深色和浅色下的可读性。
5. **交易与仓位状态**：开仓价格等输入不改；最终开仓符合度／建议用颜色提示；计算仓位区域做多使用绿色背景、做空使用红色背景。
6. **整体风格**：减少大面积纯黑灰造成的单调感，参考苹果使用的鲜艳色彩；保留中性色文字层级，同时加入清晰、适量的彩色重点。

验收时同时检查电脑／手机、手动浅深色／跟随系统、按钮反馈、盈亏与风险语义、文字对比度。颜色之外保留文字或图标提示，避免仅靠颜色表达能否开仓。
