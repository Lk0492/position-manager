# 仓位管理器

一个专业的加密货币仓位计算工具，帮助交易者精准计算合约仓位、严格控制风险。

![Platform](https://img.shields.io/badge/Platform-PWA-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

## 功能特点

### 核心计算
- **智能仓位计算** - 根据账户总额和最大亏损比例自动计算最优仓位
- **多交易所支持** - 支持币安、OKX、Bybit、火币等主流交易所
- **真实杠杆计算** - 区分表面杠杆与真实风险暴露
- **盈亏比分析** - 自动计算风险回报比，评估交易价值

### 风险管理
- **逐条风险检查** - 7项风险指标实时检测
- **保本价格计算** - 考虑手续费后的真实保本点
- **预估爆仓价格** - 提前预知强平风险
- **亏损回本对照** - 警示亏损与回本的指数陷阱

### 数据管理
- **历史记录** - 本地存储所有计算记录
- **筛选过滤** - 支持按交易方向筛选历史
- **Excel 导出** - 一键导出计算明细与统计摘要

### 用户体验
- **移动端适配** - 支持添加到手机主屏幕，PWA离线可用
- **苹果风格 UI** - 简洁现代的界面设计
- **实时问候** - 根据时间段显示问候语

## 风险控制原则

### 核心公式

```
真实杠杆 = 名义仓位 ÷ 账户总额
盈亏比 = 预期盈利 ÷ 最大亏损
建议标准：盈亏比 ≥ 3:1
单笔最大亏损：账户总额的 1%~2%
```

## 安装使用

### 桌面端
直接在浏览器中打开 `index.html` 文件即可使用。

### 移动端（推荐）

1. **方式一：GitHub Pages 访问**
   - 访问: https://Lk0492.github.io/position-manager/
   - 点击浏览器菜单 → "添加到主屏幕"

2. **方式二：本地部署**
   ```bash
   # 使用任意静态服务器
   npx serve .
   # 或
   python -m http.server 8080
   ```
